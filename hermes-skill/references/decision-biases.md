# 决策偏见与排列策略

## 6 种关键偏见

| 偏见 | 含义 | 对策 |
|------|------|------|
| 锚定效应 | 第一个信息设判断锚点 | P0 维度放第1行（推荐方案最强项） |
| 近因效应 | 最后信息影响不均衡大 | 最后一行不能是推荐方案弱项 |
| 确认偏误 | 读者找支持已有偏好的证据 | 推荐方优势集中在前段 |
| 选择超载 | >7-10 决策质量下降 | 两方案最优；3-4方案用分层策略 |
| 框架效应 | 表述方式影响判断 | 永远用正面框架（"80%兼容"非"20%不兼容"） |
| 光环效应 | 一个维度好→读者默认其他也好 | 劣势维度用 badge-warning 打断光环 |

## 维度排列策略

```
推荐方案强项 → 第1-3行（锚定）
持平/参考信息 → 第4-6行（过渡）
推荐方案弱项 → 中间位置（不要首尾）
安抚/持平项 → 最后（近因效应收尾）
```
