# 数学美感细则

## 比较表间距与列宽

| 元素 | 规则 | CSS 实现 |
|------|------|---------|
| 列宽 | 推荐列最宽 ≈ 1.6x 普通列 | colgroup 百分比 |
| 间距 | 4px 基准网格：4/8/12/16/24/32/40/48/64 | padding/gap 从刻度表取值 |
| 推荐列明度 | 与背景差 15-30% | #FFF3E0 明度85% vs #ffffff 100% |
| 视觉重心 | 偏向左侧 3/5 处 | 维度+方案列占60%，建议+留白占40% |
| 外层留白 | 表格到容器边缘留白 ≥ 6% | .container { padding: 0 6%; } |
| 视觉温度 | 从"正确"到"舒服"的微调值 | 见微调表 |

## 分析报告模度比例

报告、信息页面、卡片等非表格内容，使用 1.25x 模度（major third）。

```css
--text-xs:   0.75rem;   /* 12px  — 注释/标签 */
--text-sm:   0.85rem;   /* 13.6px — 次要正文 */
--text-base: 1rem;      /* 16px  — 正文 */
--text-lg:   1.25rem;   /* 20px  — h3/卡片标题 */
--text-xl:   1.563rem;  /* 25px  — 章节标题 h2 */
--text-2xl:  1.953rem;  /* 31px  — 大标题 h1 */
```

映射：h1 → --text-2xl / h2 → --text-xl / h3 → --text-lg / body → --text-base / badge → --text-sm / .meta → --text-xs

## 比较表字号层级

| 基准 | 16px(银行/教育局/科技) | 17px(学校) |
|------|----------------------|-----------|
| thead th | 16px / 600 | 17px / 600 |
| tbody th | 15px / 600 | 16px / 600 |
| tbody td | 15px | 16px |
| cell-desc | 14px | 15px |
| dim-desc | 14px | 15px |
| legend | 15px | 16px |
| h1 | 26px | 28px |

规则：
- thead th ≥ 基准字号
- tbody th/td 比基准小 1px
- cell-desc/dim-desc 比基准小 2px
- 基准越大差值比例越小

| 受众 | font-family 顺序 | 理由 |

## 微调表（安全值 → 舒服值）

| 元素 | 安全值 | 微调值 | 理由 |
|------|--------|--------|------|
| 交替行背景 | #f4f4f4 | #f2f4f7 | 带蓝调更高级 |
| badge 圆角 | 6px | 4px | 更克制 |
| badge 内边距 | 3px 12px | 2px 10px | 轻量化 |
| th 内边距 | 16px 12px | 14px 12px | 给内容更多比例 |
| 维度列分割线 | 2px solid | 1px solid | 更含蓄 |
| 推荐列边框 | 1px | none | 靠背景色区分 |
| text-secondary | #525252 | #4B5563 | 保持可读性 |
| text-muted | #8d8d8d | #6B7280 | 不发虚 |

默认用微调值。用户说"不够"才用安全值。

## 数据-墨原则与图表选择（数据可视化补充）

### Tufte 数据-墨原则（Data-Ink Ratio）

每个页面元素要么携带数据信息，要么删除。

```
数据-墨比 = 用于展示数据的墨水 / 总墨水

适用检查：
  □ 网格线是必要的还是多余的？→ 删除垂直网格线，水平线用淡灰色
  □ 背景色有信息还是纯装饰？→ 推荐列背景有信息（"看这列"），其他背景无则去
  □ 边框有信息还是习惯？→ 无边框表（只有内容分割线）
  □ 任何渐变/投影/3D效果有数据含义吗？→ 无则去
```

### 表格 vs 图表选择

| 场景 | 推荐方式 | 理由 |
|------|---------|------|
| 对比多个方案的多个维度 | **表格** | 精确值比视觉趋势更重要 |
| 展示趋势/变化/分布 | **图表** | 视觉模式比精确值更容易识别，当前支持 bar/line/donut/radar，通过 scripts/chart_svg.py 生成 SVG 嵌入 |
| 展示排名 | 两者皆可 | 表格更精确，图表更直观 |
| 展示占比/份额 | **数据标注式表格** | 增加百分比 + 视觉进度条效果（纯 CSS） |

### Cleveland 图形感知原则（适用表格设计）

人类对不同视觉通道的感知精度不同。在表格中做视觉对比时：

| 视觉通道 | 感知精度 | 在表格中 |
|---------|---------|---------|
| 同一基线下的位置 | **最高** | 数字对齐方式（右对齐 + 等宽字体） |
| 长度 | 高 | Badge 宽度 |
| 角度 | 中 | 不使用（需要图表） |
| 面积 | 低 | 不使用（容易误判） |
| 颜色饱和度 | 低 | 只在语义标记时使用 |

**表格规则：** 数字用同一基线对齐（右对齐），不依赖颜色面积传递数量信息。
