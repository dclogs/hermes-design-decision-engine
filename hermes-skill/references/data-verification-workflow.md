# Data Verification Workflow

本用户对数据真实性要求极高。公开数据来源的对比方案，必须走两步调研法。

## 两步调研法

### Pass 1：并行搜索

3 路并发 delegate_task，覆盖各方的搜索覆盖：

```python
delegate_task(tasks=[
  {goal: "搜索 A 的数据...", toolsets: ["web"]},
  {goal: "搜索 B 的数据...", toolsets: ["web"]},
  {goal: "搜索行业基准...", toolsets: ["web"]},
])
```

### Pass 2：独立核实（必做）

**不要合并到 Pass 1！** Pass 2 是独立的 delegate_task 调用。

```python
# 每个数据点逐一核实，不合并
delegate_task(tasks=[
  {goal: "核实数据点1...", toolsets: ["web"]},
  {goal: "核实数据点2...", toolsets: ["web"]},
  {goal: "核实数据点3...", toolsets: ["web"]},
])
```

**为什么必须分开：** 本 session 的 Pass 1 报告"温州商学院用新开普"是错的（实际是正元智慧）。如果依赖单一 pass 的结果，会直接输出错误数据给用户。
```

### 数据审计标准

| 置信度 | 含义 | 展示 |
|--------|------|------|
| ✅ 高 | 原始 URL 可查，官方来源 | 直接引用 |
| ⚠️ 中 | 行业研报转述/间接来源 | 标注"据 XX 报告" |
| ❌ 不存在 | 全网无匹配 | **丢弃，不使用** |

## 本 session 经验教训

1. **不要信任子 agent 的厂商识别能力。** 子 agent 可能搜索到过时信息（新开普2015年提到过就当真），必须独立核实。
2. **政府采购网是最可靠的来源。** 浙江政府采购网、中国政府采购网上的中标公告/单一来源公示是金标准。
3. **学校官网新闻稿可信度高**，但注意区分"官方新闻"和"转载软文"。
4. **满意度数据最容易编造。** 非官方的百分比数据默认标记为"不存在"直到找到原始出处。
5. **行业市场份额数据几乎都是间接转述。** 标注"据 XX 研报"而非直接引用。
