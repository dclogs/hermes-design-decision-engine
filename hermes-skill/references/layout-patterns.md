# 布局模式库（Layout Patterns）

根据场景选择布局骨架，在加载 popular-web-designs 后参考具体实现。

---

## Pattern 1：方案对比（面向决策者）

**适用场景：** 两个产品/方案的横向对比，给决策层看
**参考范例：** Stripe Pricing / IBM Carbon Comparison

```
Hero（一句话标题 + 一句话定位）
  → 推荐框（结论先行）
    → 对比表（6-10 维度，sticky 首列 + 推荐列高亮）
      → 预期异议框（标注已知问题）
        → Footer（数据来源 + 版本）
```

**关键特征：**
- 推荐框在表格上方（先结论后依据）
- 表格不超过 10 行（选择超载控制）
- 数据来源逐条标注（可信度闭环节点）

---

## Pattern 2：行业分析报告（面向管理层）

**适用场景：** 行业格局/趋势分析，给校领导/企业高管翻阅
**参考范例：** Notion 产品内页 / Linear Changelog

```
Hero（标题 + 副标题 + 元信息）
  → 核心结论框（3-5 条关键发现）
    → Chapter 1: 定位差异（嵌入比较表）
      → Chapter 2: 区域落地（卡片网格）
        → Chapter 3: 产品对位（嵌入比较表）
          → Chapter 4: 关系/机会分析（文字 + 三层关系图）
            → 预期异议框
              → Footer（完整来源列表 + 免责说明）
```

**关键特征：**
- 核心结论在页面顶部，不藏
- 多章节用 `<section>` 分隔
- 卡片网格用 Every Layout Cluster 实现自动换行
- 来源列表必须完整，每个数据点可追溯

---

## Pattern 3：转型路径指南（面向团队内部）

**适用场景：** 团队内部分享/培训材料，不同角色看不同部分
**参考范例：** Linear Docs / Stripe Documentation

```
Hero（标题 + 一句话定位）
  → 核心结论框
    → 背景变化（3-4 个 key change，每个带影响标注）
      → 分角色路径（等宽卡片网格 → 70后/80后/90后）
        → 管理建议（分点说明）
          → 学习资源时间线
            → 预期异议框
              → Footer（免责说明）
```

**关键特征：**
- 三段卡片布局（等宽，每张卡同结构：现状→挑战→路径→目标→定位转变）
- 卡片使用 .age-card 模板，状态/颜色按角色区分
- 正文和卡片字号逐级递减（模度比例 1.25x）

## 模式选择速查

| 用户场景 | 推荐模式 | 不推荐 |
|---------|---------|--------|
| 选哪个方案好？ | Pattern 1 对比 | Pattern 3（太散）|
| 行业趋势怎么看？ | Pattern 2 报告 | Pattern 1（太窄）|
| 团队怎么转型？ | Pattern 3 指南 | Pattern 1（太表格化）|
| 向客户提案 | Pattern 1 + 2 混合 | Pattern 3（太内部）|
