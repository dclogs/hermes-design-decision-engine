# 认知负荷与心流

## 认知负荷三类型（Sweller, 1988）

**内在负荷（Intrinsic Load）**
由信息本身的复杂度决定。对比表的维度数越多，内在负荷越高。
→ 控制维度 ≤ 10

**外在负荷（Extraneous Load）**  
由信息呈现方式决定。不一致的行高、多余的网格线、无意义的背景色。
→ 格式塔原则消除

**相关负荷（Germane Load）**
帮助读者构建心理模型的有用负荷。推荐列高亮 + 选型建议列引导"正面对比"。
→ 增加

## 心流四通道（Csikszentmihalyi）

```
技能高 + 挑战高 → 心流（最优体验）
技能高 + 挑战低 → 无聊（维度太少）
技能低 + 挑战高 → 焦虑（维度太多）
技能低 + 挑战低 → 冷漠（表与读者无关）
```

## 应用

- 对比表 6-10 行 = 心流区间
- 推荐框 = 降低外在负荷（读者不需要自己总结）
- dim-desc 字体稍小稍淡 = 降低外在负荷（不干扰主要判断）
- badge 颜色语义统一 = 降低外在负荷（不需要每行都读文字）
