# 叙事设计 + 接受美学 + 戏剧学

## 叙事弧线

```
开头（前2行）：问题引入——"你们现在的痛点是什么？"
中间（3-6行）：冲突展开——"方案A和B在这几个维度上分出了优劣"
结尾（7-8行）：解决方案——"所以推荐方案B"
```

## 场景化命名示例

| 属性名（❌） | 场景名（✅） |
|-------------|-------------|
| 脱机消费 | 断网了还能不能打饭 |
| 支付渠道 | 学生能用哪些方式付钱 |
| 对账能力 | 财务老师每天对账要花多久 |
| 实施周期 | 从签约到用上要等多久 |
| IoT能力 | 门禁水电能不能一个平台管 |

## 接受美学：三种读者的解读路径

```
行长：推荐框(0.5s) → 价格维度(2s) → badge-danger位置(1s) → 结论
技术：维度名(1s/个) → cell-desc(3s/个) → 对接细节 → 验证结论
财务：价格行(0.5s) → 结算方式(2s) → 实施周期 → 确认成本可控
```

所有路径指向同一结论。

## 戏剧学：投屏表演节奏

```
开幕（推荐框）：直接给结论 → 观众锚定
展开（前3行）：逐步验证 → 观众信服
转折（中间弱项）：诚实面对 → 观众信任
收束（底部总结）：回到结论 → 观众记住
```

## 物理隐喻（补充）

物理定律是解释行业规律的有力框架。

| 隐喻 | 含义 | 页面用途 |
|------|------|---------|
| **熵** | 系统随时间趋向无序。不维护的旧系统必然退化。 | 解释"为什么需要迁移"——现有系统在增熵 |
| **惯性** | 一个系统一旦启动，倾向于保持当前状态。 | 解释"为什么切换困难"——组织惯性是真实成本 |
| **均衡** | 市场最终会趋于稳定配置。 | 解释"为什么现在选就是这个方向"——行业在收敛 |
| **杠杆** | 小投入在某些节点上可以放大效果。 | 推荐方案时强调关键差异点的放大效应 |
| **势能** | 积累的差距会在某个时刻释放。 | 解释"现在不选以后代价更大" |

**使用原则：** 每个隐喻只用一个句子解释，不展开。放在叙事弧线的"冲突"段，增加论证的重量感。

## 历史叙事（补充）

在行业分析报告中，历史背景是天然的叙事开场。

```
问：这篇报告为什么要现在看？
答：因为一年前 X，现在 Y，所以..."
```

**历史叙事三要素：**
1. **起点** —— 一个读者熟悉的事实（"2018 年之前，校园卡还是 IC 卡"）
2. **变化** —— 发生了什么转折（"2020 年移动支付普及后，旧系统开始不够用"）
3. **现状** —— 现在的处境（"当前市场上已有 5 家主流方案，但技术路线分化明显"）

**检查：** 历史叙事是否引入了阅读者不知道但又需要理解的信息？如果是，2 句话内说完。超过 3 句的历史背景 → 对读者来说太深了，应该去掉或移至附录。
