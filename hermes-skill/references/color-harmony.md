# 色彩和谐系统（从单一品牌色推导整表配色）

品牌色通常是 1 个值（如银行蓝 #1565C0）。但一个对比表需要 6 个色值协调工作。以下是从单一品牌色推导整套配色的方法。

## 色相环定位

```
品牌色 → 定位到色相环上的角度（H 值）
  #1565C0 → H=210°（蓝色区域）
  #E65100 → H=22°（橙色区域）
  #0D47A1 → H=224°（深蓝区域）
```

## 四角色彩角色

| 角色 | 占比 | 来源 | 说明 |
|------|------|------|------|
| **主色** | 60% 视觉效果 | 品牌色本身 | Header底边线、表头下划线、强调标记 |
| **辅助色** | 30% 视觉效果 | 主色 ±30° 旋转 | 次要标记、链接、次要 badge |
| **强调色** | 10% 视觉效果 | 主色补色（±180°）或对比色 | 推荐标记、正向指标 |
| **背景色** | 大面积 | 主色降饱和度+提明度 | 推荐列高亮、标签背景 |

## 从主色推导辅助色

```
主色 H=210°（蓝）
  辅助色 = H=210-30=180°（青）或 H=210+30=240°（紫蓝）
  
主色 H=22°（橙）
  辅助色 = H=22-30=352°（粉红）或 H=22+30=52°（黄橙）
```

**实用简化原则：** 对比表不需要严格的色相环补色。更实用的做法是：

```
辅助色 = 主色保持相同色相，降低饱和度 50%，降低明度 20%
强调色 = 主色保持相同色相，提高饱和度 20%，降低明度 30%（更深更纯）
背景色 = 主色保持相同色相，降低饱和度 80%，提高明度 40%（极浅）
```

## 实战推导示例

### 银行蓝 #1565C0 → 完整色系

```
品牌色:   #1565C0   H=210  S=74  L=42
主色:     #1565C0   保持
辅助色:   #42A5F5   同色相，降S至60%，提L至60%
强调色:   #0D47A1   同色相，提S至80%，降L至32%
高亮背景: #E3F2FD   同色相，降S至10%，提L至90%
成功色:   #2E7D32   不依赖品牌色，独立语义（绿）
警告色:   #E65100   不依赖品牌色，独立语义（橙）
错误色:   #C62828   不依赖品牌色，独立语义（红）
中性灰:   #6B7280   不依赖品牌色，独立灰度
```

### 学校橙 #E65100 → 完整色系

```
品牌色:   #E65100    H=22  S=100  L=45
主色:     #E65100    保持
辅助色:   #FF8F00    同色相，降S至80%，提L至55%
强调色:   #BF360C    同色相，提S至100%，降L至40%
高亮背景: #FFF3E0    同色相，降S至15%，提L至92%
```

## 色彩温度控制

```
高饱和度（S≥70）+ 中明度（L=40-50）= 视觉冲击强 → 适合小面积强调
低饱和度（S≤30）+ 高明度（L≥80）= 视觉柔和 → 适合大面积背景

使用原则：
  badge/标签 → 高饱和度+中明度（一眼看到）
  表格背景/高亮列 → 低饱和度+高明度（不抢内容）
  文字 → 中性灰（不偏色，保持可读）
```

## 不要用纯黑纯灰

```
❌ #000000（纯黑）→ 对比过强，刺眼
✅ #161616 或 #1a1a1a → 接近黑但有深度

❌ #cccccc（纯灰）→ 死板
✅ #d1d5db 或 #e5e7eb → 带微量蓝或暖调的灰
```

## 配色自检清单

```
□ 主色 + 辅助色是否在色相环上相差 30° 以内或视觉协调？
□ 高亮背景是否使用了主色的极浅版本（而非白色+透明）？
□ 文字色是否与背景色有足够对比（WCAG AA ≥ 4.5:1）？
□ 整套配色中是否有"跳脱"的颜色（孤立的不和谐色）？
□ 成功/警告/错误三个语义色是否一眼可辨（绿=好 橙=注意 红=不好）？
```
