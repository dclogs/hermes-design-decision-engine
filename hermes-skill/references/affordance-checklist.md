每项对应一个 HTML/CSS 元素。缺任何一项读者都需要额外解释。

```
□ 粘性列 → position: sticky; left: 0;
   afford: "这是维度索引"
```

## Gestalt 原理补充（实验心理学吸收）

格式塔完形原理解释了为什么某些布局"看起来对"、某些"感觉不对"，即使说不清原因。

| 原理 | 含义 | 页面应用 |
|------|------|---------|
| **接近性**（Proximity） | 距离近的元素被视为一组 | 组内间距 < 组间距 → 用 padding/gap 控制 |
| **相似性**（Similarity） | 视觉相似的元素被视为同一类 | 同层级元素用同字号/同色 → 一眼看出"这些是同级的" |
| **闭合性**（Closure） | 大脑自动补全不完整的图形 | Badge 用圆角矩形，读者自动识别"这是个标签" → 不要用奇形怪状的背景 |
| **连续律**（Continuity） | 沿直线或曲线排列的元素被视为连续 | 左对齐列 = "一直读下去" → 首列 sticky 保持可见 |
| **图形-背景**（Figure-Ground） | 视觉自动分离前景和背景 | 推荐列高亮 = 图形，其他列 = 背景 → 对比度 ≥ 15% 才能分离 |
| **共同命运**（Common Fate） | 朝相同方向运动的元素被视为一组 | 对比表同一行 hover 高亮全行 → "这是一行的数据" |

### 自检

```
□ 接近性：不同信息组的间距是否明显大于组内间距？
□ 相似性：同层级元素是否在视觉上统一（字号/色/间距一致）？
□ 图形-背景：最重要的信息（推荐列/推荐框）是否从背景中清晰分离？
□ 连续律：阅读方向是否被打断？sticky 列是否保持可见？
□ 闭合性：形状是否使用读者熟悉的模式？Badge 是圆角矩形而非怪异形状？
```
