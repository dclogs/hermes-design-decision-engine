# Examples

This directory contains real outputs generated by the Hermes Design Decision Engine framework.

## Submitting Your Example

If you've used this framework to generate a comparison matrix, industry report, or guide, we'd love to include it here:

1. Save your output HTML in the appropriate subdirectory
2. Include a `meta.md` with:
   - Audience and context
   - Which disciplines were most impactful
   - Any issues or gaps discovered (honest failures welcome — they feed the output-tracker)
3. Open a PR

## Directory Structure

```
examples/
├── comparison-matrix/    # Vendor/product comparison tables
│   ├── meta.md
│   └── report.html
├── industry-report/      # Market analysis, landscape reports
│   ├── meta.md
│   └── report.html
└── guide/               # Transformation roadmaps, adoption guides
    ├── meta.md
    └── report.html
```
